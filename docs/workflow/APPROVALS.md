# Approvals

Only Brandon edits this file. The agent is blocked from writing it.

To approve a phase, add a line under "Approved" that starts at the very beginning of the line, in the form `Phase 1: Approved 2026-11-27`, and save. (The example in this sentence does not count, because the line does not start with "Phase".)

Phases count only in order: approving Phase 3 does nothing until Phase 2 is approved. To reopen a phase, delete its line (and the lines of every later phase). The agent can then edit that phase's files again.
